# Product

## Register

product

## Users

MADCP is used by its operator to configure integrations, inspect authentication
state, manage credentials, and obtain MCP endpoints for AI clients.

## Product Purpose

Provide one dependable administrative surface for multiple MCP integrations.
Success means the operator can understand each integration's state and complete
authentication without consulting source code.

## Brand Personality

Direct, calm, and practical. The interface should feel like a well-made
administration utility rather than a marketing site.

## Anti-references

Avoid generic blue-on-white SaaS styling, tiny helper text, ornamental cards,
decorative gradients, and code instructions that are difficult to select or
copy.

## Design Principles

1. Make operational state immediately legible.
2. Put instructions beside the action they explain.
3. Prefer familiar controls and plain language.
4. Keep commands copyable and credentials clearly distinguished from examples.
5. Use restrained styling so the integration content remains primary.

## Accessibility & Inclusion

Use readable default-size body text, strong contrast, visible keyboard focus,
non-color state labels, responsive layouts, and optional dark mode that honors
the user's saved or system preference.
